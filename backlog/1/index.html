Теоретический справочник по основным командам терминала
cat

Команда cat (сокращение от concatenate — объединять) предназначена для чтения и вывода содержимого файлов. Это одна из самых базовых команд в Unix-подобных системах.

Основное предназначение — быстрый просмотр содержимого текстовых файлов без необходимости открывать их в редакторе. Команда читает файл последовательно от начала до конца и выводит результат в стандартный поток вывода.

Базовый синтаксис

cat [файл...]

Если не указать имя файла, cat будет читать из стандартного ввода (клавиатуры). Можно указать несколько файлов — они будут выведены последовательно.

cat filename.txt
Выводит содержимое файла filename.txt на экран.
cat file1.txt file2.txt
Последовательно выводит содержимое нескольких файлов.
cd

Команда cd (change directory) используется для навигации по файловой системе. Это основной инструмент для перемещения между каталогами в терминале.

Текущая директория определяет, где будут выполняться все последующие команды.

Базовый синтаксис

cd [путь]

Путь может быть абсолютным (начинается с корня /) или относительным (относительно текущей директории).

cd /home/user/Documents
Абсолютный путь — переход в указанную директорию независимо от текущего местоположения.
cd Documents
Относительный путь — переход в папку Documents внутри текущей директории.
cd ..
Переход на один уровень вверх к родительской директории.
cd ../..
Переход на два уровня вверх.
tree

Команда tree визуализирует структуру каталогов в виде дерева. Это инструмент для понимания иерархии файловой системы.

В отличие от ls, которая показывает только содержимое текущей папки, tree рекурсивно обходит все подкаталоги и выводит их в наглядном древовидном формате.

Базовый синтаксис

tree [опции] [директория]

Без аргументов выводит дерево текущей директории. Можно указать путь к любой другой директории.

tree
Выводит полную структуру текущей директории со всеми вложенными файлами и папками.
tree -a
Показывает все файлы, включая скрытые (начинающиеся с точки).
Пример вывода
.
├── src
│   ├── main.js
│   └── utils
│       └── helpers.js
└── package.json
ls

Команда ls (list) выводит содержимое директорий. Это одна из самых часто используемых команд в терминале.

Команда имеет множество опций, которые позволяют настроить формат вывода и фильтрацию.

Базовый синтаксис

ls [опции] [путь]

Без аргументов выводит содержимое текущей директории. Можно указать путь к любой другой директории.

ls
Простой вывод файлов и папок в текущей директории. Показывает только имена.
ls -a
Показывает все файлы, включая скрытые (начинающиеся с точки).
ls -la
Показывает все файлы в подробном формате с информацией о правах доступа, владельце, размере и дате изменения.
ls -lt
Показывает файлы в подробном формате, отсортированные по времени модификации (новые первые).
Пример вывода ls -la
total 48
drwxr-xr-x   6 user  staff   192 Jan 15 10:30 .
drwxr-xr-x  25 user  staff   800 Jan 14 09:15 ..
-rw-r--r--   1 user  staff  2048 Jan 15 10:30 readme.txt
drwxr-xr-x   3 user  staff    96 Jan 12 14:20 .config
-rwxr-xr-x   1 user  staff  1024 Jan 10 08:45 script.sh

Расшифровка первого столбца (права доступа):

  • Первый символ: d (директория), - (файл), l (символическая ссылка)
  • Следующие 9 символов: права для владельца, группы и остальных (rwx = read, write, execute)
Скрытые файлы

В Unix-подобных системах файлы и директории, начинающиеся с точки, считаются скрытыми.

Примеры:

  • .gitignore — конфигурация Git
  • .env — переменные окружения
  • .bashrc — настройки терминала
