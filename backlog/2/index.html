Работа с файлами

Теоретический справочник по командам создания, копирования и перемещения файлов
mkdir

Команда mkdir (make directory) создаёт новые директории в файловой системе. Это базовая команда для организации файловой структуры.

При создании директории можно указать как относительный путь (от текущей директории), так и абсолютный путь (от корня файловой системы).

Базовый синтаксис

mkdir [опции] [имя_директории]

Можно создать одну или несколько директорий одновременно, перечислив их имена через пробел.

mkdir folder_name
Создаёт директорию с именем folder_name в текущей директории.
mkdir folder1 folder2 folder3
Создаёт несколько директорий одновременно.
mkdir -p path/to/nested/folder
Создаёт вложенную структуру директорий. Флаг -p (parents) создаст все промежуточные директории, если они не существуют. Без этого флага команда выдаст ошибку, если родительских директорий не существует.
Пример использования
mkdir projects
mkdir -p projects/web/frontend/components
Первая команда создаст папку projects. Вторая создаст всю цепочку вложенных папок, даже если промежуточных директорий не существует.
cp

Команда cp (copy) копирует файлы и директории из одного места в другое. Оригинальный файл остаётся на месте, создаётся его копия.

При копировании сохраняется содержимое файла, но могут измениться метаданные (владелец, время создания) в зависимости от используемых флагов.

Базовый синтаксис

cp [опции] источник назначение

Источник — это файл или директория, которую нужно скопировать. Назначение — куда копировать (путь или новое имя).

cp file.txt copy.txt
Копирует file.txt в новый файл copy.txt в текущей директории.
cp file.txt /path/to/destination/
Копирует файл в указанную директорию, сохраняя исходное имя файла.
cp -r folder /path/to/destination/
Копирует директорию со всем её содержимым. Флаг -r (recursive) необходим для копирования директорий. Без него команда откажется копировать папки.
cp file1.txt file2.txt /destination/
Копирует несколько файлов в указанную директорию. Последний аргумент всегда должен быть директорией назначения.
Практический пример
cp report.pdf backup/
cp -r project_folder /media/usb/
Первая команда создаёт копию файла в папке backup. Вторая копирует всю папку проекта на USB-накопитель.
Важные особенности

Если файл назначения уже существует, cp перезапишет его без предупреждения. Будьте внимательны при копировании.

При копировании директорий обязательно используйте флаг -r, иначе получите ошибку.

mv

Команда mv (move) перемещает или переименовывает файлы и директории. В отличие от cp, оригинальный файл удаляется из исходного местоположения.

Одна и та же команда используется как для перемещения файлов между директориями, так и для их переименования. Если источник и назначение находятся в одной директории — это переименование, в разных — перемещение.

Базовый синтаксис

mv [опции] источник назначение

Источник — файл или директория для перемещения. Назначение — новое местоположение или новое имя.

mv oldname.txt newname.txt
Переименовывает файл oldname.txt в newname.txt в той же директории.
mv file.txt /path/to/destination/
Перемещает файл в другую директорию, сохраняя его имя.
mv file.txt /path/to/destination/newname.txt
Перемещает файл в другую директорию и одновременно переименовывает его.
mv folder /new/location/
Перемещает директорию со всем содержимым. В отличие от cp, для mv не нужен флаг -r — команда автоматически работает с директориями.
mv file1.txt file2.txt /destination/
Перемещает несколько файлов в указанную директорию.
Практический пример
mv draft.txt final.txt
mv old_project archive/
mv document.pdf ../parent_folder/report.pdf
Первая команда переименовывает файл. Вторая перемещает папку в архив. Третья перемещает файл на уровень выше и переименовывает его.
Важные особенности

Команда mv необратима — после перемещения или переименования восстановить исходное состояние без резервной копии невозможно.

Если файл назначения существует, mv перезапишет его без предупреждения.

При перемещении файлов в пределах одной файловой системы операция происходит мгновенно (просто изменяется запись в таблице файлов). При перемещении между разными дисками файл физически копируется.

nano

Nano — это простой текстовый редактор для терминала. Он удобен для быстрого редактирования конфигурационных файлов, написания скриптов и заметок прямо в командной строке.

В отличие от более сложных редакторов (vim, emacs), nano имеет интуитивный интерфейс с подсказками в нижней части экрана, что делает его идеальным выбором для новичков.

Базовый синтаксис

nano [имя_файла]

Если файл существует, он откроется для редактирования. Если не существует — будет создан новый файл при сохранении.

Основные команды

Все команды в nano начинаются с клавиши Ctrl. В подсказках внизу экрана символ ^ означает Ctrl.

Ctrl + O
Сохранить файл (WriteOut). После нажатия появится запрос подтверждения имени файла. Нажмите Enter для сохранения под текущим именем или введите новое имя.
Ctrl + X
Выход из редактора. Если есть несохранённые изменения, nano спросит, хотите ли вы их сохранить. Нажмите Y для сохранения, N для выхода без сохранения.
Ctrl + K
Вырезать текущую строку или выделенный текст. Вырезанный текст помещается в буфер обмена.
Ctrl + U
Вставить текст из буфера обмена в позицию курсора.
Ctrl + W
Поиск текста в файле. Введите искомую строку и нажмите Enter.
Ctrl + G
Открыть справку по командам nano.
Типичный рабочий процесс
nano config.txt
[редактирование текста]
Ctrl+O (сохранить)
Enter (подтвердить имя файла)
Ctrl+X (выйти)
Навигация в редакторе
  • Стрелки — перемещение курсора
  • Ctrl + A — начало строки
  • Ctrl + E — конец строки
  • Ctrl + Y — страница вверх
  • Ctrl + V — страница вниз
Отмена действий

В базовой версии nano нет встроенной функции отмены (Undo). Однако в современных версиях (2.8+) можно использовать:

  • Alt + U — отменить последнее действие
  • Alt + E — вернуть отменённое действие (Redo)

Если эти комбинации не работают, ваша версия nano может быть устаревшей. В таком случае единственный способ отменить изменения — выйти без сохранения и открыть файл заново.
